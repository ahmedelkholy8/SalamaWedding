# محمد & F | دعوة زفاف رقمية فاخرة

دعوة زفاف رقمية فاخرة بتصميم إسلامي راقٍ، مخصصة للهواتف المحمولة.

## ✨ المميزات

### التصميم
- 🎨 تصميم فاخر إسلامي بخلفية خضراء زمردية داكنة
- ✨ تأثيرات ذهبية معدنية راقية
- 🌙 أنماط هندسية إسلامية شفافة
- 📱 تصميم mobile-first محسّن لجميع الأجهزة
- 🎭 حركات سلسة وأنيقة

### التجربة
- 🎬 شاشة افتتاحية سينمائية
- 📖 عرض البسملة والآية القرآنية
- 👰‍♀️ عرض أنيق لأسماء العروسين
- 📅 تفاصيل الزفاف الكاملة
- ⏰ عد تنازلي حي
- 📍 موقع القاعة مع خريطة
- 📆 إضافة للتقويم (ICS)
- 💬 تأكيد الحضور عبر WhatsApp
- 🎵 موسيقى خلفية (اختيارية)
- 📤 مشاركة الدعوة

### الأداء
- ⚡ تحميل سريع
- 🎯 أداء عالي على الموبايل
- 🔋 محسّن للبطارية
- 🌐 يعمل بدون اتصال بعد التحميل الأول

## 🚀 النشر على GitHub Pages

### الطريقة التلقائية (موصى بها)

1. ادفع الكود إلى GitHub:
```bash
git add .
git commit -m "Luxury wedding invitation redesign"
git push origin main
```

2. فعّل GitHub Pages:
- اذهب إلى **Settings** → **Pages**
- اختر **GitHub Actions** كمصدر

3. انتظر 1-2 دقيقة للنشر التلقائي

### الموقع سيكون متاحاً على:
```
https://ahmedelkholy8.github.io/SalamaWedding/
```

## 🎵 إضافة الموسيقى

1. ضع ملف الصوت في مجلد `gh-pages/` باسم `song.mp3`
2. ارفع إلى GitHub:
```bash
git add gh-pages/song.mp3
git commit -m "Add wedding music"
git push origin main
```

## ⚙️ التخصيص

### تعديل بيانات الزفاف

افتح `src/data/weddingData.ts` وعدّل:

```typescript
export const weddingData = {
  groom: "Mohamed Salama",
  bride: "F",
  date: "2026-10-10",
  venue: "فيلا سعودي - قاعة رويال",
  mapsUrl: "https://maps.app.goo.gl/...",
  whatsappNumber: "+201000000000", // رقم WhatsApp
  // ... المزيد
};
```

### الألوان

الألوان محددة في `src/index.css`:

```css
:root {
  --emerald-950: #071E18;  /* أخضر داكن جداً */
  --emerald-900: #0B3027;  /* أخضر داكن */
  --gold: #C6A15B;          /* ذهبي */
  --gold-light: #E4C878;    /* ذهبي فاتح */
  --ivory: #F5F0E6;         /* عاجي */
}
```
